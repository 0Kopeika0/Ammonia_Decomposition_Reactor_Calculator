Название: Калькулятор реактора разложения аммиака / Ammonia Decomposition Reactor Calculator

Стек: Python, Tkinter, Matplotlib, NumPy, SciPy

Что делает: Рассчитывает объём реактора идеального вытеснения для разложения аммиака при заданных температуре, давлении, расходе и составе смеси; строит графики зависимостей и выводит материальный баланс.
